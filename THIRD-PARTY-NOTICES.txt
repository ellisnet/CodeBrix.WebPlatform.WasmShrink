CodeBrix.WebPlatform.WasmShrink is the WebAssembly size optimizer of the
CodeBrix.WebPlatform web application platform: a NuGet package that holds the
wasm-opt program for each supported build platform, and a small .NET library
that finds, prepares and runs the copy for the current machine.

The .NET library (the CodeBrix.WebPlatform.WasmShrink assembly) and its tests
were written for this project and incorporate no third-party source code.
