LICENSE-Unicode.txt - the Unicode, Inc. notice of the UTF conversion code
                      compiled into wasm-opt
================================================================================
wasm-opt is built with binaryen's full DWARF support (BUILD_LLVM_DWARF=ON),
which compiles in a cut-down copy of LLVM's Support and DebugInfo libraries
(binaryen/third_party/llvm-project/). One of those files,
third_party/llvm-project/ConvertUTF.cpp (with its header
include/llvm/Support/ConvertUTF.h), is derived from Unicode, Inc.'s
ConvertUTF code and carries Unicode, Inc.'s own copyright and permission
notice, which LLVM's licence (LICENSE-Llvm.txt beside this file) does not
contain. That notice asks to appear with all copies, so it is reproduced here,
VERBATIM, from lines 8-44 of binaryen/third_party/llvm-project/ConvertUTF.cpp
at binaryen tag version_133 (commit fba5005a132d85d578be5bd010e0487ed8e2ce3e).
The same lines appear, unchanged, in include/llvm/Support/ConvertUTF.h.

That ConvertUTF.cpp.o really is linked into wasm-opt is recorded per build in
output/<rid>/third-party-evidence.txt (the linker map) - see BUILD-PROVENANCE.txt.

This file is not an upstream file; it was assembled for
CodeBrix.WebPlatform.WasmShrink by copying that header, unchanged, under the
separator below.
